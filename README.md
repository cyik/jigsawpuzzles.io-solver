Jigsawpuzzles.io solver by cyik

An automated jigsaw puzzle solver that tells you where every piece of a puzzle fits on a puzzle board. Simply screenshot the puzzle piece using snipping tool (Win + Shift + S) and the solver6.py scans the piece and overlays a green box directly on your screen at the exact spot where it belongs. Read the README word file to see setup instructions, you must follow it or it won't work.

P.S: Solver6.py is the iteration with the new feature that tells you where the piece goes directly on the screen using a greenbox overlay. Solver4.py is the old iteration that worked pretty well and accurately. You should play around with both and see which one you like the best.
